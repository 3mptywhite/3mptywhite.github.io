## 微分公式

若 $y=f(x)$，则 $dy=f'(x)\,dx$。

| 原函数 $f(x)$ | 导数 $f'(x)$ |
| --- | --- |
| $c$ | $0$ |
| $x^\alpha$ | $\alpha x^{\alpha-1}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x\ln a$ |
| $\ln\lvert x\rvert$ | $\dfrac{1}{x}$ |
| $\log_a x$ | $\dfrac{1}{x\ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\sec^2 x$ |
| $\cot x$ | $-\csc^2 x$ |
| $\arcsin x$ | $\dfrac{1}{\sqrt{1-x^2}}$ |
| $\arctan x$ | $\dfrac{1}{1+x^2}$ |

### 求导法则

| 法则 | 公式 |
| --- | --- |
| 线性 | $(\lambda u+\mu v)'=\lambda u'+\mu v'$ |
| 乘积 | $(uv)'=u'v+uv'$ |
| 商 | $\left(\dfrac{u}{v}\right)'=\dfrac{u'v-uv'}{v^2}$ |
| 链式 | $\dfrac{d}{dx}f(u)=f'(u)u'$ |

## 积分公式

| 被积函数 | 不定积分 |
| --- | --- |
| $x^\alpha\;(\alpha\ne-1)$ | $\displaystyle\int x^\alpha\,dx=\dfrac{x^{\alpha+1}}{\alpha+1}+C$ |
| $\dfrac{1}{x}$ | $\displaystyle\int\dfrac{1}{x}\,dx=\ln\lvert x\rvert+C$ |
| $e^x$ | $\displaystyle\int e^x\,dx=e^x+C$ |
| $a^x$ | $\displaystyle\int a^x\,dx=\dfrac{a^x}{\ln a}+C$ |
| $\sin x$ | $\displaystyle\int\sin x\,dx=-\cos x+C$ |
| $\cos x$ | $\displaystyle\int\cos x\,dx=\sin x+C$ |
| $\sec^2 x$ | $\displaystyle\int\sec^2 x\,dx=\tan x+C$ |
| $\csc^2 x$ | $\displaystyle\int\csc^2 x\,dx=-\cot x+C$ |
| $\dfrac{1}{1+x^2}$ | $\displaystyle\int\dfrac{1}{1+x^2}\,dx=\arctan x+C$ |
| $\dfrac{1}{\sqrt{1-x^2}}$ | $\displaystyle\int\dfrac{1}{\sqrt{1-x^2}}\,dx=\arcsin x+C$ |

### 常用积分法则

| 法则 | 公式 |
| --- | --- |
| 线性 | $\displaystyle\int(\lambda u+\mu v)\,dx=\lambda\int u\,dx+\mu\int v\,dx$ |
| 换元 | $\displaystyle\int f(g(x))g'(x)\,dx=\int f(t)\,dt$，其中 $t=g(x)$ |
| 分部 | $\displaystyle\int u\,dv=uv-\int v\,du$ |

## 定积分

若 $F'(x)=f(x)$，则：

$$
\int_a^b f(x)\,dx=F(b)-F(a)
$$

$$
\frac{d}{dx}\int_a^x f(t)\,dt=f(x)
$$

对称区间上，奇函数与偶函数分别满足：

$$
\int_{-a}^{a}f(x)\,dx=0,
\qquad
\int_{-a}^{a}g(x)\,dx=2\int_0^a g(x)\,dx
$$

其中 $f$ 为奇函数，$g$ 为偶函数。
