# 概率论概念地图

这张图用来直观看概念之间的逻辑关系。它不是完整知识树，而是当前学习进度内的主干地图。

## 主干关系

```mermaid
graph TD
  A["随机试验"] --> B["样本空间 Ω"]
  B --> C["样本点 ω"]

  D --> E["事件运算"]
  E --> F["德摩根律"]
  D --> G["概率 P(A)"]
  G --> H["概率性质"]

  G --> K["条件概率 P(A|B)"]

  B --> P["随机变量 X: Ω -> R"]
```

## 关键依赖链

### 从随机试验到概率

```mermaid
graph LR
  A["随机试验"] --> B["样本空间"]
  B --> C["事件"]
  C --> D["概率"]
```

含义：先明确试验，再列出所有可能结果，然后把某些结果组成事件，最后给事件赋概率。

### 从条件概率到贝叶斯

```mermaid
graph LR
  A["概率"] --> B["条件概率"]
  B --> C["乘法公式"]
  C --> D["全概率公式"]
  D --> E["贝叶斯公式"]
```

含义：贝叶斯公式不是孤立公式，它来自条件概率、乘法公式和全概率公式。

### 从事件到随机变量

```mermaid
graph LR
  A["样本空间 Ω"] --> B["随机变量 X"]
  B --> C["实数轴上的分布"]
  C --> D["分布函数 CDF"]
  C --> E["PMF"]
  C --> F["PDF"]
```

含义：随机变量把样本空间上的随机结果映射到实数轴，分布描述概率在实数轴上的摆放方式。

## 三组容易混淆的关系

### 互斥 vs 独立

```mermaid
graph TD
  A["互斥"] --> B["不能同时发生: A∩B=∅"]
  C["独立"] --> D["互不改变概率: P(A|B)=P(A)"]
  B --> E["若 P(A)>0 且 P(B)>0, 互斥通常不独立"]
  D --> E
```

### PMF vs CDF

```mermaid
graph LR
  A["PMF: 每个点的概率"] --> B["累加"]
  B --> C["CDF: 到 x 为止的累计概率"]
  C --> D["跳跃高度"]
  D --> A
```

### PDF vs CDF

```mermaid
graph LR
  A["PDF: 局部密度"] --> B["积分"]
  B --> C["CDF: 累计面积"]
  C --> D["求导"]

```
