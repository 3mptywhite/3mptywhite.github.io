TECHNICAL NOTE / 03

手电筒双锥衰减改造

方案对比原生曲线想法过程参数传递

考虑过的三种方案

Light Function：给灯光加一个材质遮罩

材质输出一个数值，控制灯光哪些地方亮、哪些地方暗。可以用贴图，也可以直接用数学节点生成光斑。图中第二组控制核心与外围，第三组加了圆环和缺口。

优点： 形状自由，方便调参和做动画。取舍： 传统路径需要先绘制遮罩，再用于照明；只做简单径向分层时，可以考虑更直接的实现。

UE 官方文档：Light Functions

IES：按出光方向查配光表

IES 记录“朝这个方向发出多少光”。UE 把数据导入为专用纹理，灯光计算时按方向读取。图中第四组的亮环，就是某一圈方向的光强较高。

优点： 适合还原具体灯具的配光。取舍： 修改光斑通常要换配光文件，不能像材质实例一样直接拖动核心半径。图中的两份 IES 是教学数据。

UE 官方文档：IES Light Profiles

两盏聚光灯：一盏照核心，一盏照外围

把两盏 SpotLight 放在同一位置、朝向：一盏窄而亮，一盏宽而弱，照明贡献相加。

优点： 直观，核心与外围可以分别调整。取舍： 增加一盏灯的计算；都开阴影会增加成本，外围关阴影则可能出现漏光感。

UE 官方文档：Spot Lights

原生聚光灯的曲线

Inner 内保持全亮，Inner 到 Outer 逐渐衰减，Outer 外归零。 拖动下面的锥角，看光斑的过渡范围如何变化。

演示一 · 原生角度衰减

横轴为离轴半角，纵轴为线性角度倍率；不含距离、阴影与曝光。

A = saturate((cosθ − cosOuter) / (cosInner − cosOuter))²

θ 是偏离灯轴的半角。saturate 限制到 0～1，平方会把 0.5 压到 0.25。图中只比较角度衰减。

想法过程

我需要一个集中的亮核心，同时保留较弱的宽外围：核心突出目标，外围让玩家看清周边。之前做 fake light 材质时，我知道可以用函数控制这种亮度分布，于是想到：把核心和外围一起写进已有的角度衰减，能否在一盏灯里做出类似双灯的层次？

实现增加了两个控制量：Mid 决定核心的衰减范围，K 控制宽分量的权重。 当前公式如下： 

w = (cosθ − cosOuter) / (cosInner − cosOuter)
c = (cosθ − cosMid)   / (cosInner − cosMid)

A = saturate(max(K × w, c))²

演示二 · 双灯相加与双锥包络

横轴为离轴半角，纵轴为线性角度倍率；不含距离、阴影与曝光。

两盏灯是把贡献相加；这里用 max 取较大值，让核心与外围分别主导不同区域，中心峰值保持为 1。两者能形成相似的分层，但数学结果不同。图中双灯参照采用宽灯强度 K²、核心强度 1，保留相加后的峰值，不做归一化。

选择它的主要理由是保持单灯，只在原有计算中增加简单运算。 不额外放第二盏灯，不为这个效果生成传统 Light Function 遮罩，也不读取 IES 配光纹理。

参数怎样传进 Shader

实际数据分两路传入：灯的角度走逐灯参数，K 走视图参数。

数据 从哪里设置 CPU 做什么 Shader 从哪里读取
Inner / Outer SpotLight 原有属性 计算外锥余弦、内外锥余弦差的倒数 原有 SpotAngles 参数
Mid 新增 MidConeAngle 计算 cosMid 与 1/(cosInner−cosMid) LightSourceRadiusAndLength 的 z、w
K 后处理设置 SpotlightDualAttenuationK 写入 View 的统一参数 View.SpotlightDualAttenuationK

灯组件的设置先进入渲染侧的 SceneProxy，由它准备灯光参数；渲染器将这些数值打包传给 GPU。Shader 取出角度参数和 K，代入双锥公式，再继续参与原来的距离衰减、阴影和表面照明计算。

因此，Mid 可以逐灯调整，当前实现的 K 则作用于同一视图中采用这段逻辑的灯。核心改动位于项目定制的移动端灯光路径。

曲线依据原项目代码整理；上方 UE5.4.4 场景用于比较 Light Function 与 IES，未移植原项目双锥代码。Light Function 的具体开销取决于引擎版本和是否采用 Atlas。
