Houdini LOD2 制作流程

从 UE 导出原有树木资产，经 AO 烘焙与 Houdini 处理，生成可调整的各级 LOD 模型。

导出资产Houdini 操作烘焙与导入参数说明导出结果

1. 从 UE 导出资产

导出树木资产到独立文件夹，勾选导出 LOD 选项，保留后续生成所需的层级数据。

2. Houdini 基本操作与叶片导出

使用 CreateTreeTools 工具文件。点击节点的蓝色眼睛切换显示，在视图中按 F 聚焦物体。选中节点后，可在参数面板中调整对应参数。

  • file 节点负责导入 FBX。路径不正确时，需要先修正路径。
  • rop fbx 节点负责导出模型。设置路径后，点击 Save to Disk。
  • 在 UE 模型导入节点读取刚导出的 FBX，再设置 LOD0 树叶模型导出节点，导出叶片用于 AO 烘焙。

3. AO 烘焙与模型导入

在 3ds Max 中，将天光结果烘焙到 LOD0 树冠的顶点色。导入和导出时，检查系统单位保持一致。

将烘焙后的树叶模型导入 Houdini，再导入美术制作的单个叶片模型。单个叶片需要准备好形状与 UV，UV 使用通道 0。

4. 调试视图与参数

点击 debug_mode 节点的蓝色眼睛查看模型效果，通过 Control_set 面板调节 LOD2 的 Billboard 叶片与插片叶片。

Select Input 显示内容
0 LOD2 最终效果
1 生成的 VDB 与原树叶范围对比
2 Billboard 模型及对应轴心点
3 Billboard 模型与 VDB 对比
4 红色为保留的插片树叶，绿色为将要删除的范围

CreateTreeMesh 参数

参数 作用
Recal pivot 是否重新计算单个叶片模型的轴心。0 为重新计算，1 为使用 FBX 原始效果，通常无需修改。
Single Billboard Scale 整体 Billboard 面片大小，与后续缩放参数相乘决定最终大小。
PointSeparation 控制 Billboard 面片的间距和疏密。
Base Voxel Size 控制 VDB 对树叶细节的保留程度。数值越大，细节越少、模型越光滑。
Base Surface add 控制 VDB 模型的鼓胀程度。
Peak Distance 控制 Billboard 点的扰动范围。
NormalDir Min/Max Value 控制面片随机朝向的范围。
pscale Min/Max Value 控制面片随机缩放范围，与整体缩放参数共同作用。
Delete Range Offset 控制 LOD2 插片树叶的保留范围。

5. 导出各级 LOD 并重新导入 UE

依次设置各级模型的输出路径，导出 FBX 后重新导入 UE。检查材质、Billboard 颜色与 LOD 切换效果，避免沿用测试材质造成颜色不一致。
